# alexa-x-claude

Poser des questions à Claude depuis Alexa : **« Alexa, demande à Claude… »**.

V1 : une skill Alexa personnalisée en français (mode développement) relaie la question à l'API Claude et lit la réponse, avec relances dans la même conversation.
